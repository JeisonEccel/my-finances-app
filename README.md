# My Finances App

I'm building this project while learning the basics of the `dart` and `flutter`.
It is the front end project to use with [My Finances API](https://github.com/JeisonEccel/my-finances-api).

## The APP

This app is used to manage personal finances with accounts, categories, and even shared partners.

## Resources

- [Flutter Docs](https://docs.flutter.dev/)

## Getting Started

- Clone the api repository for [My Finances API](https://github.com/JeisonEccel/my-finances-api)
- Follow the instruction to run MyFinancesAPI
- Clone this repository from [My Finances APP](https://github.com/JeisonEccel/my-finances-app)
- Install Flutter and required dependencies
- Run the application at `/lib/main.dart`
